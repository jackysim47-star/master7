# MASTER7 V17.140 profile catalogue count

Release `17.0.0-selfbuilt.140-profile-catalogue-count` makes the selected
platform's cached game count use the selected profile catalogue. Normal MYR,
MY1 1:100, and Free Credit MYR now report 92, 92, and 88 respectively in both
the selected game count and selected platform cache count.

This release does not change provider contracts, wallet behavior, credentials,
DNS, bank targets, payment records, game sessions, Render capacity, or
databases. It does not enable deposits, game launches, payouts, real payments,
live games, or `productionReady`.
