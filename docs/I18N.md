# Interface languages

The member portal, admin console and standalone account pages support `zh-CN`, `en` and `ms` using the same bundled dictionary in `shared/translations.json`. No external translation service runs in the browser or server.

Visitors select a language in the portal header or the links above standalone pages. The allowlisted `master7_locale` cookie retains an explicit selection for one year (`Path=/`, `SameSite=Lax`, `Secure` on HTTPS). This preference is public presentation data; it grants no access. Invalid values are ignored. Without an explicit selection, the current brand's saved language is used, falling back to Simplified Chinese. Browser language is not substituted for the brand default.

React uses a provider per mounted portal and explicit translation calls for application-owned labels and errors. Language changes retain mounted form input. Server rendering uses request-local `AsyncLocalStorage`; concurrent visitors do not share mutable language state. Dynamic values are HTML-escaped, including numeric entities for CJK text, before static interface text is translated. Form values, URLs, scripts and styles are excluded from that translation pass. Display attributes are escaped after translation.

Announcement titles and bodies, support subjects, messages and replies, audit records, brand names and taglines, game names and bank details remain in their original language. Never pass customer content into `translate()` or change a canonical status to its display translation. Ticket options explicitly submit their original Chinese values. JSON APIs and exported accounting data retain their existing contracts. Monetary currency stays MYR and business dates stay in `Asia/Kuching`.

When adding interface text, add both English and Malay entries. An unknown key displays the original text rather than inventing a translation. Native browser validation messages follow the browser's installed language; application validation and business errors use the selected interface language. Third-party payment-method labels and supplier names remain as supplied.

Validation:

- `npm run test:i18n`: cookie allowlist, complete dictionaries, explicit React literal coverage, HTML data and attribute preservation.
- `MASTER7_CHROMIUM_PATH=/usr/bin/chromium npm run test:browser:i18n`: three languages at 390px and 1440px, public/account/admin/readiness pages, preference persistence, brand fallback, original content, translated login errors, draft preservation, canonical ticket updates and access denial.
- Existing member journey and dialog browser suites verify the default Chinese workflow remains compatible.

These interface changes do not activate suppliers, payment companies or financial transactions, restore member data, or attest a cloud deployment.
