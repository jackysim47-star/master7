目前不能把“有后台登录”或“前台有按钮”当成厂家接口已经连接。厂家须提供
正式 API、商户环境、签名、回调、查询、测试与对账资料，再逐项完成无资金
联调和钱包账本验收。平台不会在资料不完整时猜测接口，也不会提前给会员加
余额。

## 给厂家的核对项目

1. MYR 正式商户 ID、可用银行/通道、金额限制、手续费和结算周期。
2. 创建订单、主动查单、取消/退款或冲正的正式 URL、方法、字段和示例。
3. 签名字段顺序、编码、时间戳、重放限制与密钥轮换方式。
4. 回调来源认证、成功确认正文、重试周期、事件 ID 和重复通知规则。
5. 沙箱或无资金测试账号，以及成功、失败、待支付、过期和重复回调用例。
6. 日终结算文件、退款/冲正和差异处理流程。
