# MASTER7 V17 奖励、返水与 VIP 功能范围

日期：2026-11-03。此文件将用户补充的完整奖励需求整理为实施范围；它不是已上线功能，也不授权发放真钱或奖金。

## 用户要求纳入的功能

游戏大厅先按 5 个分类规划：老虎机/电子、真人、体育、捕鱼、街机/小游戏。候选前端已加入 5 类筛选；只匹配明确的供应商分类标签，未知标签保留在“全部”列表。供应商实时目录未就绪时筛选保持禁用；分类数量不代表已有真实游戏数量，也不代表已可启动或结算。

| 模块 | 目标能力 | 当前状态 |
|---|---|---|
| 返水 / 水钱 | 按已确认的有效流水、游戏类别、比例、周期和封顶规则计算；支持会员明细及汇总对账 | 仅有租户隔离的非启用规则草稿与审批记录；计算/发放待开发 |
| 红包 | 活动创建、总额与份数、领取窗口、会员资格、单人限领、过期与未领余额处理 | 仅有非启用规则草稿；红包分发/领取待开发 |
| Bonus / 优惠 | 新客、充值、回归、节日、免费旋转或其他活动；按通道、游戏、次数、有效期及领取条件配置 | 仅有非启用规则草稿；不发奖 |
| VIP | 多级门槛、升级/保级周期、权益、返水倍率及变更记录 | 仅有非启用规则草稿；等级和权益待确认 |
| 推荐、合作方返佣 / 分红 | 关联关系、结算周期、计算基数、扣除项、负数处理、审批、对账与 CSV | 仅有非启用规则草稿；旧回执记录过草稿及审批方向，计算/付款未实现 |
| 优惠券 / 积分 | 发放、领取、兑换、次数限制、到期、撤销及审计 | 待开发与定义兑换规则 |

## 每项活动必须配置的规则

- 目标会员与资格条件、活动开始/结束时间（Asia/Kuching）、适用地区和 MYR 金额。
- 每会员领取次数、总预算、单人上限、是否可与其他活动叠加，以及异常/重复账号处理。
- 现金、Bonus、返水、红包和合作方佣金分账显示；不可将未到账奖励混成可提款现金。
- 有效投注或流水倍数、合资格游戏/厂牌、提款上限、有效期、取消/退款/冲正处理。
- 规则版本、审批人、活动发布/暂停/撤回记录及每次计算的可复算明细。

## 安全和财务边界

- 统一采用幂等活动领取与不可重复的奖励账本；并发领取、重复回调或重试不能重复发奖。
- 返水、Bonus、红包和佣金分别记账，并记录来源活动、会员、订单/会话引用、规则版本和审核记录。
- 未验收的游戏供应商流水不能用于自动计算奖励；不得拿展示目录、模拟数据或未核实的交易统计计算可提款金额。
- 用户此前讨论的“RM188、12 倍流水（RM2,256）、提款上限 RM50”只保留为待审核草稿，不自动启用。
- “分红”尚未定义为股东分红、活动返利还是合作方净收入分成。任何计算基数、比例、亏损/退款扣除、结算周期和付款主体未书面确认前，只能作为草稿记录，不能显示为保证收益或自动付款。
- 启用真钱奖励之前，必须完成适用许可/合同核实、供应商 UAT、MYR 账务对账、反滥用测试、回滚测试及负责人的正式批准；未通过时只允许本地合成数据验收。

## 验收清单

1. 资格、游戏范围、时区窗口、上限、流水、提款限制与到期边界均有自动测试。
2. 并发领取、重复请求、通知重放、服务中断、拒绝、撤回和冲正均不会重复记账或损坏余额。
3. 会员仅能查看本人奖励；老板/员工仅按既有角色和租户授权查看/审批；敏感账务操作留审计。
4. 后台可按 MYT 日期导出计算来源、活动版本、金额、状态及汇总；抽样可从记录复算。
5. 本地/UAT 测试完成后仍需供应商与生产账本验收；本地通过不代表可发真钱。

## 本地草稿工作流实现（2026-11-03）

- V17 门户候选新增后台“奖励规则草稿”：返水、红包、Bonus、VIP、分红/合作分成五类可创建、编辑、提交审核及审核/退回。员工受当前租户范围约束；只有老板/租户老板可审核；每次操作写入审计。
- 审核通过的状态仍为 `approved_draft`，无启用状态或发奖/钱包接口。金额、比例及资格为待审批文本；分红定义仍未确认。
- 新增 SQLite/PostgreSQL 迁移及 HTTP 测试。`npm run test:promotions` 的两种数据库通过；测试覆盖匿名/会员拒绝、跨租户拒绝、员工不能审核、老板审核、审计和钱包流水数保持为零。`npm run build`、`npm run test:i18n`、`git diff --check` 通过。
- 这是本地候选代码；未推送到 Sites/Render，未发布到生产，也未启用任何奖励。

- 补充双人复核：规则创建人不能批准自己的草稿；后端在租户范围和事务内强制检查，界面隐藏自批按钮。SQLite 与 PostgreSQL HTTP 测试均覆盖自批拒绝。
- 结构化字段已落库：MYR 币种、Asia/Kuching 生效日期、资格、奖励比例/固定额/单人上限/预算、流水倍数、单人次数及五类游戏范围；服务器校验金额上限 RM100,000、比例/流水范围、日期有效性与前后顺序、类别白名单。SQLite/PostgreSQL 使用新增迁移，接口返回不缓存规则资料。字段只保存于草稿，不触发计算或发放。
- 后台新增规则草稿 CSV 导出，列出结构化规则、状态和审核元数据；仅限后台角色且限定当前租户。CSV 对以 `= + - @` 等开头的用户文本加安全前缀，使用附件响应并设置 no-store。SQLite/PostgreSQL HTTP 测试验证匿名/会员拒绝、公式注入防护、无会员资料导出。
